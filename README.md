# Lindsey D. Stead

Full-stack software developer in British Columbia. I build TypeScript products on Postgres: schema, API, UI, tests, and deploy. When a model is in the product, code decides what is allowed to stick.

## Selected work

### [CivilProposal](https://www.civilproposal.com)
React, Vite, Express, Drizzle, Postgres, and Stripe. Deployed on Fly in Toronto, with Supabase in Montreal. Municipal and climate datasets are resolved in code, and each claim stores its source. OpenAI drafts proposal sections for a person to review.

### [HelpKelowna](https://www.helpkelowna.com)
React, Express, Drizzle, and Postgres. A verification job keeps a claim only when the quoted sentence is on the page. Rejected claims go to a change log.

### [PDF Autofiller](https://github.com/lindseystead/ai-pdf-autofiller)
Python, FastAPI, and Docker. Fills AcroForm PDFs from JSON using field aliases. The model stays off unless an API key is set. [Playground](https://lindseystead.github.io/ai-pdf-autofiller/)

### [Food bank check-in](https://github.com/lindseystead/foodbank-checkin-system)
Kiosk and staff dashboard in seven languages. The API is not in this repository. [Demo](https://foodbank-checkin-tan.vercel.app/)
